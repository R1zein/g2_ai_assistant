# esgram — Telegram-бот

Упрощённая, «ботовая» версия идей AyuGram (разбор — в
[`research/ayugram.md`](research/ayugram.md)). Отдельный процесс в `apps/bot`,
на [grammY](https://grammy.dev). Полноценная версия «с наворотами» — это
клиент/приложение, и часть функций возможна только там (см. ниже).

У бота два режима работы: **в группах** (через обычный Bot API) и **в твоих
личных чатах** (через Telegram Business — гост-режим).

## В группах

- **Трекинг правок.** При редактировании сообщения бот публикует «было →
  стало» и пишет это в лог.
- **Архив медиа.** Ответь на фото/видео/кружок/голосовое словом «сохрани»
  (или `/save`), либо пришли медиа боту в личку.
- **Управление чатом «как у Ириса»** (ответом на сообщение, для админов):
  - `/admin [титул]` — выдать админку, `/unadmin` — снять, `/title <текст>` —
    задать титул (до 16 символов);
  - `Мут` / `/mute`, `Анмут` / `/unmute`; `Бан` / `/ban`, `Разбан` / `/unban`,
    `Кик` / `/kick`;
  - `Варн` / `/warn [причина]`, `/unwarn`, `/warns` — варны; по достижении
    лимита (`warnLimit`, по умолчанию 3) выдаётся мут и счётчик сбрасывается;
  - `/del` — удалить сообщение; `/pin`, `/unpin` — закрепить/открепить;
  - `/setwelcome <текст>` — приветствие новичкам (плейсхолдеры `{name}`,
    `{username}`, `{title}`), `/welcomeoff` — выключить;
  - `Спасибо` / `/rep` (ответом) — поднять репутацию, `/unrep` — понизить,
    `/top` — топ чата.
- **Веб-панель.** Чаты (вкл/выкл бота и трекинга правок), муты, лог правок,
  архив медиа.

> `/admin` выдаёт набор «доверенного» админа (удаление, ограничения, закрепление,
> видео-чаты), но **не** право назначать других админов и менять инфо чата.
> Снять титул/админку бот может только у тех, кого назначил сам — так работает
> Bot API.

Общие команды: `/start`, `/help`, `/status`, `/enable`, `/disable`.

### Ограничения Bot API в группах

- **Удаление сообщений в группах Telegram ботам не сообщает** — переслать
  удалённое в группе нельзя (в личке — можно, через Business, см. ниже).
- Чтобы бот видел обычные сообщения и ключевые слова (`Мут`, `сохрани`) в
  группах, выключи privacy mode: @BotFather → `/setprivacy` → Disable. Слэш-
  команды работают и с включённым.
- Для управления чатом бот должен быть **админом** с правами: удалять
  сообщения, банить и ограничивать участников, закреплять.

## В личных чатах — гост-режим (Telegram Business)

Так работает «как @tonzbot»: удалённые и изменённые сообщения в **твоих
собственных** личных чатах, плюс перехват одноразовых медиа. Это штатная
функция Telegram, а не обход: ты сам подключаешь бота к своему аккаунту.

**Подключение.** Нужен **Telegram Premium**. В приложении Telegram:
Настройки → Telegram Business → Чат-боты → укажи `@esgrambot` и выдай права
(как минимум «читать сообщения», для мута — «удалять сообщения»). Отключается
там же.

Что делает после подключения:

- **Удалённое** сообщение собеседника бот присылает тебе обратно (ловит
  событие `deleted_business_messages`).
- **Изменённое** — присылает «было → стало».
- **Одноразовые/самоуничтожающиеся медиа** скачиваются в момент прихода, пока
  не сгорели.
- **Мут в личке.** В панели у любого перехваченного сообщения есть кнопка «мут
  личка»: входящие от этого человека бот будет удалять по мере прихода
  (нужно право «удалять сообщения»).
- Бот **не** вызывает «прочитать», так что твои чаты остаются непрочитанными —
  это и есть гост-режим.

**Честно про приватность.** Право «читать сообщения» даёт боту доступ ко **всем**
твоим личным перепискам, а «удалённые» — это сообщения собеседников, которые
они пытались убрать. Данные (перехваченные сообщения, медиа) лежат на твоём
сервере в `BOT_DATA_DIR`. Включай только на своём аккаунте и понимая это.

## Запуск

```bash
npm install
cp .env.example .env            # заполните BOT_TOKEN (и BOT_WEB_TOKEN для панели)
npm run start -w @g2/bot
```

Токен берётся у @BotFather. Храните его только в `.env` — файл в `.gitignore`.

Панель (если задан `BOT_WEB_TOKEN`): `http://localhost:8788/?token=<BOT_WEB_TOKEN>`.

### Настройка в группе

1. Добавьте бота в группу.
2. Назначьте админом с правами **удалять сообщения** и **ограничивать
   участников**.
3. В @BotFather выключите privacy mode.
4. `/status` в группе покажет текущее состояние.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `BOT_TOKEN` | — | Токен от @BotFather (обязателен) |
| `BOT_DATA_DIR` | `data/bot` | База JSON и файлы архива медиа |
| `BOT_OWNER_IDS` | — | ID владельцев: команды и панель доступны везде |
| `BOT_EDIT_LOG_LIMIT` | `500` | Сколько правок хранить на чат |
| `BOT_TEXT_CACHE_LIMIT` | `5000` | Кэш текстов для вычисления «было» при правке |
| `BOT_WEB_TOKEN` | — | Секрет панели; пусто → панель выключена |
| `BOT_WEB_PORT` / `BOT_WEB_HOST` | `8788` / `0.0.0.0` | Адрес панели |

## Устройство

```
apps/bot/src/config.ts   чтение окружения
apps/bot/src/store.ts     JSON-хранилище (чаты, муты, правки, медиа, business)
apps/bot/src/media.ts     извлечение и скачивание вложений
apps/bot/src/util.ts      общие хелперы (имена, экранирование)
apps/bot/src/bot.ts       grammY: группы — сообщения, правки, команды, роутинг
apps/bot/src/moderation.ts Iris-подобное: админки, титулы, варны, приветствие, репутация
apps/bot/src/business.ts  Telegram Business: гост-режим, анти-удаление/правка
apps/bot/src/web.ts       Fastify-панель
apps/bot/src/index.ts     запуск long polling + панели
```

Хранилище — тот же приём, что у сервера: один JSON-файл, атомарная запись;
медиа лежат файлами в `<BOT_DATA_DIR>/media`, в базе только индекс.

## Приватность

Бот удаляет и ограничивает участников только там, где он открыто админ, —
это модерация, а не скрытая слежка. Архив медиа и лог правок доступны владельцу
через панель, защищённую токеном; файлы лежат на вашем сервере. Чужие удалённые
сообщения бот не хранит — потому что Telegram их ему и не отдаёт.
