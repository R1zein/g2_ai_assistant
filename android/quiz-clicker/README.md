# Quiz Clicker (Android)

Плавающая стрелка поверх экрана для викторины AhaSlides про ФК «СПЛАВ».
После нажатия на стрелку приложение само читает вопрос на странице и
нажимает правильный вариант, а затем кнопку «Отправить» — на каждом новом вопросе.

## Как это работает

Приложение — служба специальных возможностей (Accessibility Service):

- рисует стрелку поверх всех окон (без отдельного разрешения «поверх других приложений»);
- читает текст страницы из браузера (Chrome отдаёт дерево веб-элементов службам);
- узнаёт вопрос по фразе из базы, находит на экране вариант с текстом правильного
  ответа и кликает его через `ACTION_CLICK` (без эмуляции пальца, работает даже пока
  вариант ещё «въезжает» анимацией), а в том же проходе — «Отправить»;
- скорость: проверка на каждое изменение страницы и дополнительно каждые 16 мс (кадр);
  пока вопрос уже узнан, а вариантов ещё нет, ищется только текст ответа одним запросом,
  без обхода всей страницы;
- если клик не сработал (через 0,7 с нет «Отправлено»), повтор жестом-тапом, потом снова кликом;
- если текст ответа не нашёлся — жмёт вариант по фиксированному месту (номер 1–4),
  отсчитывая от кнопки «Отправить»: на скриншотах варианты всегда стоят на одном
  и том же расстоянии над ней, даже если вопрос в 2 или 3 строки;
- как только на экране появляется «Отправлено» — вопрос считается отвеченным.

Стрелка: короткое нажатие — старт/стоп (зелёная ▶ / красная ■), перетаскивание —
переместить, долгое нажатие — скопировать весь текст с экрана в буфер обмена.

## База ответов

Редактируется прямо в приложении, по строке на вопрос:

```
фраза из вопроса | правильный ответ | номер варианта (1-4)
```

Встроенная база (10 вопросов со скриншотов) — в `Answers.kt`. Вопроса 11 на
скриншотах не было: добавьте строку в приложении и нажмите «Сохранить»,
затем выключите и снова включите стрелку. Регистр, «ё», кавычки и пробелы
при сравнении не важны.

## Сборка

APK собирает GitHub Actions (`.github/workflows/quiz-clicker-apk.yml`) при каждом
пуше в `android/quiz-clicker/**`: вкладка **Actions** → последний запуск
«Quiz Clicker APK» → артефакт `quiz-clicker-apk` (zip с `app-release.apk`).

Локально: Android SDK + JDK 17, затем `./gradlew assembleRelease`.

## Установка

1. Установить APK (разрешить установку из неизвестных источников).
2. Открыть Quiz Clicker → «Включить службу» → включить «Quiz Clicker — стрелка».
   На Android 13+ при сообщении «Ограниченная настройка»: Настройки → Приложения →
   Quiz Clicker → ⋮ → «Разрешить ограниченные настройки», затем снова включить службу.
3. Открыть викторину, держать стрелку сбоку (не над вариантами), нажать её.
