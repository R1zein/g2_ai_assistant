# G2 AI Assistant

ИИ-помощник для умных очков **Even Realities G2**, приложение для **Even Hub**.
Работает на Claude (Anthropic), подключён к Gmail и Google Календарю, знает
геопозицию и умеет присылать уведомления на дисплей очков.

Ключевой сценарий: на почту приходит письмо о брони отеля → помощник сам
вытаскивает из него дату, адрес и код брони, кладёт событие в Google Календарь,
а потом отвечает на очках на вопрос «во сколько заселение и где это?» — вслух
заданный, голосом.

```
Next: in 2h 10m                                              84%

15:40  [F] LH992 Prague - Munich
18:20  [H] Hotel Astoria - check-in
tmrw 09:00  Standup
tmrw 13:30  [R] Lunch, Cafe Savoy

Hold to ask                                                  1/2
```

---

## Что умеет

**Голосовой ассистент.** Зажали тачпад на дужке (или на кольце R1) — говорите,
отпустили — ответ на дисплее. Микрофонный массив очков, PCM 16 кГц, распознавание
речи на стороне сервера, дальше агент Claude с инструментами.

**Два режима.** Переключаются из контекстного меню очков или с панели телефона,
в шапке HUD горит значок `web`, когда интернет включён.

- **Быстрый** — ваш календарь, почта, брони, геопозиция плюс то, что модель знает
  сама. Ответ за пару секунд.
- **С интернетом** — то же плюс серверный веб-поиск и чтение страниц на стороне
  Anthropic. Медленнее и дороже за вопрос, зато отвечает на что угодно.

Обычные вопросы работают в обоих режимах и вашей почты не касаются — «как
по-чешски „счёт, пожалуйста“», «сколько грамм в восьми унциях», «что значит эта
ошибка». Это модель отвечает из своих знаний, без единого вызова инструмента. А
всё, что меняется — счёт матча, цена, расписание, статус рейса — требует
включённого интернета.

**Понимает контекст, а не просто ищет.** У модели есть инструменты к календарю,
почте, сохранённым броням, геопозиции, погоде, геокодеру и часам — и она их
связывает:

- «Что дальше?», «Что у меня завтра?»
- «Во сколько заселение и какой адрес?»
- «Какой у меня номер брони в отеле?»
- «Успею на поезд в 18:20?» — сопоставит текущую позицию с бронью
- «Нужна ли куртка там, куда я лечу?» — координаты назначения + погода
- «Напомни зарегистрироваться на рейс в 18:00»
- «Во сколько закрывается эта аптека?» — с включённым интернетом

**Почта → календарь, автоматически.** Раз в 15 минут сервер просматривает свежие
письма, отдаёт кандидатов модели на структурированное извлечение и зеркалит
найденные брони в отдельный календарь «Travel & Bookings». Отели, рейсы, поезда,
автобусы, аренда авто, рестораны, билеты, записи на приём, доставки.

**Уведомления.** За сутки, за два часа и за полчаса до брони на дисплей приходит
карточка. Если очки были офлайн — карточка дождётся следующего запуска.

**Осторожность с фактами.** Системный промпт запрещает угадывать время, гейт,
номер комнаты и код брони: только из инструмента. Неверная деталь на HUD хуже,
чем «у меня этого нет».

## Устройство

```
apps/glasses     приложение Even Hub (Vite + TS, Even Hub SDK 0.0.15)
apps/server      Node 22 + Fastify: OAuth, Gmail, Календарь, агент Claude, STT
packages/shared  общий протокол — типы, которые импортируют обе стороны
docs/            архитектура, установка, взаимодействие, API, публикация
```

Почему нужен сервер: приложение Even Hub — это веб-страница внутри Flutter
WebView. В ней нельзя держать ключ Anthropic, нельзя пройти OAuth Google,
действует полный CORS, и она живёт только пока открыта. Поэтому очки — это
терминал, а все ключи, фоновая работа и расписание живут на сервере.

Подробности — в [`docs/architecture.md`](docs/architecture.md).

## Быстрый старт

Нужны: Node 22+, ключ Anthropic, аккаунт Google, Even App 2.2.10+.
Очки не обязательны — есть симулятор.

```bash
npm install

cp .env.example .env
# заполните ANTHROPIC_API_KEY, GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET
npm run dev:server

cp apps/glasses/.env.example apps/glasses/.env
# укажите VITE_API_BASE_URL — адрес сервера, доступный с телефона
npm run dev:glasses
```

В симуляторе:

```bash
npx evenhub-simulator http://localhost:5173
```

На реальных очках:

```bash
cd apps/glasses && npx evenhub qr     # отсканируйте код в Even App
```

Дальше очки покажут ссылку и восьмизначный код. Откройте ссылку на телефоне,
войдите в Google — очки подхватят это за несколько секунд и сразу начнут
первое сканирование почты.

Пошаговая настройка Google Cloud, туннеля и распознавания речи —
[`docs/setup.md`](docs/setup.md).

## Управление

| Жест | Что делает |
|---|---|
| **Долгое нажатие** | Включает микрофон — говорите, пока держите |
| **Отпустить** | Отправляет вопрос |
| **Одно нажатие** | Закрыть карточку / вернуться к расписанию / листать |
| **Двойное нажатие** | Системный диалог выхода |

Всё это работает и с дужки очков, и с кольца R1.

## Ключи и стоимость

**Ключ приносит каждый свой.** На панели телефона есть поле для `sk-ant-…` —
ключ проверяется через Anthropic ещё до сохранения, шифруется AES-256-GCM под
мастер-ключом из `ENCRYPTION_KEY` и расходуется с вашего аккаунта. В базе лежит
только шифротекст и последние четыре символа. `ANTHROPIC_API_KEY` на сервере
теперь необязателен и работает как запасной для тех, кто свой не добавил;
`REQUIRE_USER_API_KEY=true` требует личный ключ от всех.

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `ASSISTANT_MODEL` | `claude-opus-5` | Ответы на вопросы |
| `EXTRACTION_MODEL` | `claude-haiku-4-5` | Извлечение броней из писем |
| `ASSISTANT_EFFORT` | `medium` | Быстрый режим: ответ на HUD, глубина обменяна на задержку |
| `DEEP_EFFORT` | `high` | Режим с интернетом всё равно ждёт сеть |
| `EXTRACTION_EFFORT` | `low` | Задача узкая и хорошо описанная |

Извлечение — один вызов на письмо, и при большой почте это основная статья
расходов. Письмо ≈ 3k входных токенов (системный промпт закэширован) + 300
выходных:

| | за письмо | 1000 писем |
|---|---|---|
| `claude-opus-5` | $0.0225 | $22.50 |
| `claude-haiku-4-5` | $0.0045 | $4.50 |

Haiku здесь не только дешевле. Anthropic API *ограничивает генерацию схемой*
(`output_config.format` + zod), поэтому запись из 18 полей либо приходит целиком
и правильно типизированной, либо не приходит вовсе. JSON-режим у
OpenAI-совместимых провайдеров гарантирует валидный JSON, но не валидную схему —
это отдельный слой валидации с ретраями. А ошибка в разборе даты не видна: она
молча уезжает в календарь неправильным событием.

Системные промпты кэшируются (`cache_control: ephemeral`) отдельно под каждый
режим, волатильная часть — часы, геопозиция, заряд — идёт после точки
кэширования, чтобы не сбрасывать префикс.

## Приватность

- Refresh-токен Google никогда не покидает сервер; на устройстве только bearer.
- От bearer-токена хранится лишь SHA-256.
- Ключ Anthropic шифруется AES-256-GCM, не пишется в логи и не возвращается ни
  одним эндпоинтом — только последние четыре символа.
- Область доступа к Gmail — **только чтение**; календарь — чтение и создание
  событий. Помощник не отправляет писем и не удаляет ничего.
- Тексты писем уходят в Anthropic API только на время извлечения; в базе
  остаются извлечённые поля, а не тело письма.
- Аудио нигде не сохраняется: буфер собирается на телефоне, уходит одним
  запросом и стирается.
- Брони пишутся в отдельный календарь, так что всё, что добавил помощник,
  выключается одним переключателем в Google Календаре.
- «Unpair this device» на панели телефона отзывает сессию;
  `POST /api/account/disconnect {"revokeGoogle":true}` отзывает и сам доступ
  Google.

## Разработка

```bash
npm run typecheck     # shared + server + glasses
npm test              # тесты сервера и раскладки текста
npm run build
npm run pack:glasses  # → apps/glasses/g2-ai-assistant.ehpk
```

`pack` сам подставляет хост сервера из `VITE_API_BASE_URL` в whitelist
разрешения `network` и отказывается собирать манифест, если адрес не задан, идёт
по HTTP или остался плейсхолдером. Руками эти два файла не синхронизируются —
именно на этом ломается сборка, которая «работает в симуляторе, но не на очках».

Перед первой публикацией поменяйте `package_id` в `apps/glasses/app.json`: он
должен быть уникальным в сторе, строчными буквами и без дефисов.

Весь путь до стора — [`docs/publishing.md`](docs/publishing.md).

## Что сейчас не сделано

- Очки не умеют показывать изображения в этом приложении: макет — три текстовых
  контейнера. Карты и QR-коды потребовали бы `updateImageRawData` и своего
  конвейера растеризации.
- Распознавание речи — внешнее (Google Cloud STT или OpenAI-совместимый
  endpoint). Без `STT_PROVIDER` голос выключен, вопросы можно вводить текстом
  на панели телефона.
- Хранилище — JSON-файл с атомарной записью. Для одного пользователя этого
  достаточно; интерфейс `Store` вынесен отдельно, чтобы подмена на SQLite или
  Postgres затронула один файл.
- Gmail опрашивается по расписанию, а не через push (`users.watch` + Pub/Sub).
  Задержка — до `GMAIL_SYNC_INTERVAL_MS`.
- IMU не используется. Он доступен через SDK и пригодился бы для жестов головой.
- Отправки писем нет: scope Gmail — только чтение. Отвечать на сообщения из
  других мессенджеров тоже нельзя — Even Hub SDK не даёт доступа к уведомлениям
  телефона вообще.
- Вход в личный аккаунт claude.ai невозможен: OAuth подписки предназначен только
  для Claude Code и claude.ai, публичного API к истории диалогов нет. Поэтому
  история разговоров живёт на нашем сервере, а не синхронизируется с claude.ai.
